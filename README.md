# Disease Prediction Using Ensemble Machine Learning

## Project Overview
This project implements an ensemble machine learning approach to predict diseases based on patient symptoms using a structured clinical symptom dataset.

## Objectives
- Analyze symptom-based clinical data.
- Perform data cleaning and preprocessing.
- Train and evaluate multiple machine learning models.
- Compare model performance using classification metrics.
- Identify important symptoms influencing predictions.

## Technology Stack
- Python
- PySpark / Apache Spark
- Databricks
- Pandas and NumPy
- Scikit-learn
- Matplotlib / Seaborn
- Jupyter Notebooks

## Machine Learning Models
- Decision Tree
- Naive Bayes
- Random Forest

## Dataset
Source: [Kaggle – Disease Prediction Using Machine Learning](https://www.kaggle.com/datasets/kaushil268/disease-prediction-using-machine-learning)

## Project Structure
- `notebooks/` – Model development and verification notebooks.
- `data/` – Dataset instructions.
- `models/` – Model artifact instructions.
- `dashboard/` – Dashboard screenshots.
- `report/` – Academic project report.

## Results
The models were evaluated using accuracy, precision, recall and F1-score. Random Forest and Naive Bayes achieved strong results on the prepared benchmark dataset. These results should not be interpreted as clinical validation.

## Disclaimer
This project is for educational and research purposes only. It is not intended for medical diagnosis or treatment decisions.
